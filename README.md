# Lottie scroll animation

A React page that scrubs a [Lottie](https://airbnb.io/lottie/) animation (`src/data.json`, rendered with
`lottie-web`) as you scroll. Built with [Vite](https://vite.dev/); requires Node 24.

## Available Scripts

In the project directory, you can run:

### `yarn start`

Runs the app in development mode at [http://localhost:5173](http://localhost:5173). The page reloads when you
make changes.

### `yarn test`

Runs the tests with [Vitest](https://vitest.dev/) in watch mode (`yarn test --run` runs them once).

### `yarn build`

Builds the app for production to the `build` folder. `yarn preview` serves that build locally.
